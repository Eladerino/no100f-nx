# switch/licenses/

License texts staged for the Switch release. One line per file: what each text covers.

- Apache-2.0.txt: Apache License 2.0 - the embedded fonts (Luckiest Guy, Roboto) and abseil.
- aurora-MIT.txt: MIT License - Aurora, by Luke Street.
- cryptopp-BSL-1.0.txt: Boost Software License 1.0 - Crypto++ (vendored runtime third_party).
- deko3d-zlib.txt: zlib License - deko3d (vendored).
- dolphin-COPYING.txt: Dolphin's licensing notice - most Dolphin code is GPLv2+, per-file SPDX tags, aggregate GPLv3-compatible.
- GPL-2.0.txt: GNU General Public License version 2 - the shipped Dolphin-derived files.
- libco-ISC.txt: ISC License - libco (vendored runtime third_party).
- MPL-2.0.txt: Mozilla Public License 2.0 - the SwitchWaker-derived debug server source and switch/deko/.
- pugixml-MIT.txt: MIT License - pugixml (vendored runtime third_party).
- SwitchWaker-MIT.txt: MIT License - SwitchWakerHD, by centollOS.
- toml11-MIT.txt: MIT License - toml11 (vendored runtime third_party).
- uam-LICENSE.txt: UAM license - uam (vendored; covers Mesa).

Update this index whenever the folder changes. Texts that cannot be staged from in-tree copies (libnx ISC; Dawn, SDL 3, ImGui from the toolchain and fetched trees) stay open until release time; do not copy them from memory.
